Zotero 公式粘贴

适用于 Zotero 10.0.x 的笔记插件。把复制来的 LaTeX 粘贴到 Zotero 笔记时，插件会将公式排版为可继续编辑的 Zotero 原生公式。

## 功能

- 支持单独复制公式，也支持一次粘贴包含公式的正文和表格。
- 粘贴整段富文本时保留表格、加粗、链接和行内代码。
- 支持常见的 LaTeX 定界符，包括行内公式 `\( … \)` 和 `$ … $`，以及单独粘贴的块公式 `\[ … \]` 和 `$$ … $$`。
- 笔记工具栏上的 **Σ** 按钮可以排版本篇笔记中已经粘贴成 LaTeX 源码的公式。操作可以撤销。
- 兼容 Better Notes 的富文本和 Markdown 粘贴流程。

## 安装

1. 在本仓库的 **Releases** 中打开 **v1.2.0**，从 **Assets** 下载 `zotero-math-paste-1.2.0.xpi`。如果安装包放在仓库文件列表中，也可以从那里下载。
2. 打开 Zotero 桌面版，进入 **工具 → 插件**。
3. 将下载好的 `.xpi` 原文件拖入插件窗口，按提示确认安装。升级时可以直接覆盖旧版。

## 使用

**新粘贴的内容**。复制带公式的文字或表格，在 Zotero 笔记中按 **Ctrl+V**。例如，把下面这行复制到笔记里，其中的 `x=0.75` 和 `T=4` 会自动排版为公式。

```text
用同一个归一化像素值 \(x=0.75\)，仿真步数 \(T=4\) 对比。
```

**已经粘贴成源码的内容**。打开对应笔记，点击笔记工具栏上的 **Σ**（排版本篇笔记中的公式）。该按钮会处理当前笔记的正文和表格单元格。需要恢复时，按 **Ctrl+Z**。

插件需要剪贴板或笔记中含有带定界符的 LaTeX 文本。复制来源是图片时，需要先取得公式的 LaTeX 文本。

## 兼容性

安装包适用于 **Zotero 10.0.x 桌面版**。已在 Windows 上使用 **Zotero 10.0.7** 和 **Better Notes 3.3.3** 验证富文本与 Markdown 粘贴、公式保存和已有笔记的公式排版。
